### ✨ Overview

**AINXE Studio** is a serene, aesthetic dark-mode landing page inspired by lo-fi pixel art and quiet computing. Designed as a clean single-viewport sanctuary where engineering meets calm intention.

- 🌌 **Clean Nocturnal Pixel Art:** Expansive night sky for crystal-clear readability with tranquil lake scenery anchored below.
- ⌨️ **Terminal Typing Effect:** Live typewriter animation on page load with animated retro cursor.
- 🎹 **Lo-Fi Ambient Music:** Real-time synthesized electric piano 7th & 9th chords generated via native Web Audio API (100% free, zero external latency).
- 💧 **Interactive Water Ripples:** Click anywhere on the midnight lake for animated expanding ripples and synthesized water droplet sound effects.
- 👾 **Super Mario Death Jingle:** Clicking social media icons plays an authentic 8-bit NES Mario death sound with a humorous `( x _ x )` Game Over modal.
- 📱 **Mobile First & Balanced:** Proportional navbar, zero button crowding, and clean 3-column layout on both mobile and desktop.
- 🎨 **Phosphor Duotone Icons:** Pure SVG duotone icons (`@phosphor-icons/react`), no emojis.

---

### 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 6
- **Styling:** Tailwind CSS v4
- **Animation:** Motion (`motion/react`)
- **Icons:** Phosphor Icons (`@phosphor-icons/react`)
- **Sound Engine:** Native Web Audio API (Synthesizers & Lo-Fi Generator)
- **Head & SEO:** `@unhead/react` + Schema.org JSON-LD

### 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/xyrusL/ainxe.git
cd ainxe

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
